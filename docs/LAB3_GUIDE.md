# Лабораторная №3: описание эксперимента и запуск

Метод №3 — Метрополис — Хастингс для графов. Основа — ЛР2
(<https://github.com/TeoSable/fda_lab2>): её модели, данные, бутстреп,
интервенция, расстояние W₁ и правило удаления используются без изменений.

## Вычислительный эксперимент

| Шаг | Что делается | Чем |
|---|---|---|
| Граф | G — набор рёбер из K кандидатов, на ребре e один параметр регрессии wₑ; без ребра параметр равен значению удаления из ЛР2 | `lab3_graphs.py` |
| Кандидаты | Контуры: M, R₂ (порождали данные) и Rₘ, Sₘ, E₂ (нет). Дисперсия: резонансы Зельмейера и полиномиальные члены c₀, c₂, c₋₂, c₋₄ | `lab3_circuit.py`, `lab3_graphs.py` |
| Подгонка графа | Взвешенный метод наименьших квадратов по параметрам имеющихся рёбер; χ²(G) — его минимум | `Regression.fit` (ЛР2) |
| Интервенция | y′ = y + α·s(x)·ξ; Pₑ, P′ₑ — бутстреп-распределения wₑ до и после | `conditional_noise`, `residual_bootstrap` (ЛР2) |
| Устойчивость ребра | ρₑ = среднее по реализациям ξ от W₁(Pₑ, P′ₑ), делённое на W₁(Pₑ, δ в значении удаления); uₑ = min(1, ρₑ); порог ρₑ = 1 | `marginal_w1` (ЛР2), `lab3_scoring.py` |
| Целевая функция | J(G) = ½χ²(G) + ½ ln m · (\|G\| + λ·Σuₑ), m — число наблюдений; π(G) ∝ exp(−J(G)) | `lab3_scoring.py` |
| Семплирование графов | Метрополис — Хастингс: добавить, удалить, заменить ребро; удаление предлагается с весом ε + uₑ | `graphmh/sampler.py` |
| Этап «без интервенции» | λ = 0, равномерное предложение, интервенция не выполняется | `lab3_experiment.py` |
| Этап «с интервенцией» | λ = 1, предложение по интервенции | `lab3_experiment.py` |
| Выбор | G* = argmin J по сохранённым графам цепей; сравнение с правилом ЛР2 | `lab3_experiment.py` |
| Проверка семплера | Перебором: π без интервенции для всех задач, с интервенцией для контуров (32 графа); там же точная матрица переходов — время достижения, спектральный зазор | `graphmh/sampler.py` |

Алгоритм и обоснование корректности записаны в разделе 3 ноутбука
`notebooks/lab3_metropolis_hastings.ipynb`.

## Что проверяется

- Семплер, на случайно заданном распределении по 16 графам с неравномерными весами:
  предложение — распределение с симметричным носителем; детальный
  баланс и стационарность π по точной матрице переходов; примитивность
  матрицы; эмпирические переходы цепи совпадают с точной матрицей;
  частоты сходятся к π.
- Модель: ток контуров совпадает с `rlc_current` ЛР2 при нулевых
  добавленных связях и с независимым решением `solve_ivp` при ненулевых.
- Преемственность: граф ЛР2 воспроизводит подгонку ЛР2 и её сохранённые
  бутстреп-оценки.
- Текст: `execute_lab3.py` после выполнения запускает
  `check_lab3_claims.py`; каждое утверждение ноутбука и слайдов
  проверяется по `results/lab3`, при расхождении запуск падает.
  Проверяется и то, что результаты посчитаны с текущими настройками,
  а сохранённый ноутбук совпадает с текстом `build_lab3.py` и выполнен.
- Тесты проверены мутациями: намеренная поломка формулы или правила
  (поправка Хастингса, правило границ, знаменатель ρₑ, прогрев и др.)
  роняет хотя бы один тест.

## Ограничения

- Данные те же, что в ЛР2: ток контуров синтетический, дисперсия —
  опубликованные формулы с добавленной ошибкой. Порождающий граф
  известен, поэтому совпадение с ним проверяемо.
- Интервенция — шум в отклике. Для хорошо определённого параметра
  ρₑ ∝ 1/|zₑ|, zₑ — статистика Вальда: критерий показывает, насколько
  прочно ребро определено данными, а не направление связи, и в линейном
  приближении не даёт информации сверх Δχ²ₑ. Регуляризатор усиливает
  штраф за слабо определённые рёбра; выбор графа в трёх задачах он
  не меняет.
- Регуляризатор вычисляется по тем же данным, что и χ²: π —
  распределение Гиббса, а не апостериорное p(G | y).
- ρₑ зависит от реализации шума (усреднение по 3 реализациям): у c₂
  в задачах дисперсии ρₑ чуть ниже порога, штраф uₑ при этом почти полный.
- Точное π с интервенцией считается только для контуров; для дисперсии
  (128 и 256 графов) оценка — по цепям из трёх стартов.
- При вырожденной подгонке (параметры на границах) ребро объявляется
  неустойчивым: малое W₁ в этом случае не означает устойчивости.
  В полном графе контуров так помечается и порождающее M.
- Подгонка графа — локальный оптимизатор ЛР2 из одной начальной точки.
  Проверка 20 случайными стартами: χ² улучшается у 5 из 32 графов
  контуров, все они без R₂ и имеют нулевую вероятность; π без
  интервенции меняется на 10⁻⁷ по полной вариации.
- Значения удаления M = 0 и R₂ = 10⁻⁶ Ом (из ЛР2) лежат вне границ
  подгонки, поэтому граф без ребра — не частный случай графа с ребром.
  Без R₂ при Rₘ ≠ 0 матрица сопротивлений не положительно определена;
  J таких графов на порядки больше, на выбор они не влияют.
